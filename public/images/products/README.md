# BAD BATCH product photography

Place approved cookie photos in this folder as JPEG files. Use the same filename pattern for every flavor:

| Product | Primary image | Additional gallery images |
| --- | --- | --- |
| The Usual (`the-classic`) | `the-usual-01.jpg` | `the-usual-02.jpg`, `the-usual-03.jpg` |
| Burn Notice (`the-dark`) | `burn-notice-01.jpg` | `burn-notice-02.jpg`, `burn-notice-03.jpg` |
| White Lie (`the-third`) | `white-lie-01.jpg` | `white-lie-02.jpg`, `white-lie-03.jpg` |
| Seasonal (`seasonal`) | `seasonal-01.jpg` | `seasonal-02.jpg`, `seasonal-03.jpg` |

Use only the number of photos you have. The `01`, `02`, `03` sequence keeps the primary image and gallery order consistent. Once uploaded, set each product's image field to its primary path, for example `/images/products/the-usual-01.jpg`. Additional-image gallery support remains dependent on receiving the real files.

No product photos were present when the storefront was finalized. The site keeps its restrained BAD BATCH image treatment until the real photos are supplied; it does not use sample or generated food images.
